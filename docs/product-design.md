# NEXT XI v2 제품·데이터 설계

## 목표와 화면

유소년 선수의 관찰을 다음 행동으로 연결합니다. 숫자·공개 서열보다 근거 장면·실천 과제·이전의 자신이 중심입니다. 초기 사용 단위는 보호자와 선수가 쓰는 **계정 하나의 비공개 성장 공간**입니다. 부모/선수 보기 설정은 설명 표현이며 코치·스카우터 접근 권한이 아닙니다.

**가입 → 선수·일정 설정 → 원본·분석 대상 등록 → 업로드 완료 → 서버 탐색·구간 분석 → 근거 확인 → 4주 실천 → 다음 경기 비교**

영상마다 색상·등번호·나이를 고릅니다. 색상·번호만으로 사람의 신원을 보증하거나 영상 간 동일 선수를 생체 식별하지 않습니다. 대상 스냅샷을 영상·작업에 보관합니다.

| 화면 | 주된 행동·정보 |
|---|---|
| 가입·로그인 | 보호자 이름·이메일·비밀번호, 성인·법정대리인 자기 확인 |
| 오늘 | 최근 경기·진행 상태, 오늘 실천, 컨디션과 다음 행동 |
| 경기 영상 | 원본 등록·재생, 서버 작업 상태·취소·재시도·삭제 |
| 성장 리포트 | 근거 시각이 연결된 정성 관찰, 관찰 부족 표시, 이전 경기 맥락 |
| 실천 계획 | 4주 날짜 달력, 단계별 15분 과제·일정 이동·기록·하루 루틴 |
| 내 공간 | 선수·학교·팀·수면·식사 설정, 계정·동의·내보내기·탈퇴 |

휴대폰 하단 탐색, 큰 조작 영역, 대화상자 포커스, 업로드 진행률·실패 후 재개 안내를 제공합니다. 저장 완료와 분석 성공을 구별합니다.

## 저장 구조

로컬은 SQLite `entries` 테이블, Netlify는 `next-xi-growth-v2` Blobs 저장소를 사용합니다. 원본을 공개 정적 경로에 복사하지 않고 인증된 `/api/v2/media/:videoId`가 바이트 범위로 제공합니다. 서버 작업은 해당 작업의 원본에 접근하는 한시 토큰을 사용합니다. 이는 외부 보안 인증을 받았다는 의미가 아닙니다.

| 레코드 | 주요 내용 |
|---|---|
| users·emails·sessions | 계정·보호자 자기 확인, scrypt 비밀번호 해시, 세션 토큰 해시 |
| workspaces/:userId | profile·videos·analyses·jobs·observations·practices·checkins·scheduleChanges·consents·revision |
| profile | 연령·대상·포지션·주발, 팀/경기 요일, 학교·취침·기상, 공간·장비·도움 시간, 선택 식품 제한 |
| uploads·media | 업로드 offset·조각 크기·해시·원본 조각. 중단분도 재개를 위해 남음 |
| videos | 파일 정보, 대상 스냅샷, 경기 날짜·상대 수준·출전 시간·촬영 상태 |
| jobs | 소유 계정·대상·동의, 진행·표본·구간·체크포인트, lease·재시도·오류 |
| analyses | 구간 시작/끝·모델·선수 확인, 행동·시각·확신·한계·다음 연습 |
| observations | 사람이 기록한 항목·시각·설명·선택 1~5단계 평가 |
| practices·checkins | 날짜·과제 ID·완료·메모, 수면/피로/기분/통증의 선택 기록 |
| scheduleChanges | 원래 날짜·과제 ID·이동 날짜. 중복 과제를 추가하지 않음 |
| consents | guardian·analysis·training. training은 AI 학습용 제공 여부로 기본 false, 현재 수집하지 않음 |

revision 충돌과 소유권을 확인해 저장합니다. 영상·AI 결과·작업은 서버에서 변경 가능 필드를 통제합니다. 여러 자녀의 독립 프로필, 코치 초대·팀/클럽 모델은 아직 없습니다.

## 분석과 평가의 경계

서버 FFmpeg가 길이를 확인하고 최대 120개 표본을 준비합니다. 지정 색상·번호가 함께 확인된 시점에서 최대 6개·각 12초 이하 구간을 골라 순차 저장합니다. 화면을 닫아도 서버 작업은 유지되지만 실행 시간·성공·과금은 자원과 외부 API에 좌우됩니다.

작업은 8분 예산과 체크포인트를 사용합니다. 긴 처리는 다음 실행으로 넘기고 Netlify 10분 주기 복구가 만료 작업을 재전달합니다. 기권·실패·취소는 완료와 구별합니다. 빠른 장면·가림·작은 번호·촬영 품질 때문에 플레이를 놓칠 수 있습니다. 연속 추적이나 전수 분석이 아닙니다.

AI 결과에 rating을 허용하지 않습니다. 스파이더맵은 사람 평가가 있는 항목만 표시합니다. AI 개선 관찰은 훈련 주제의 근거로 사용할 수 있지만 경기 전체 점수로 바꾸지 않습니다. AI 초안에 코치 검수 표시를 붙이지 않습니다.

숫자 경기 비교에는 동일 색상·번호·연령, 동일 포지션, 두 경기 10분 이상 출전, 출전 시간 비율 2/3 이상, 선명한 촬영, 알려진 동일 상대 수준이 필요합니다. 항목별 각 경기 사람 평가 3개 미만이면 차이를 보류합니다. 보수적인 서비스 규칙이며 검증된 전국 표준 척도가 아닙니다. AI 관찰 수 차이는 성장 점수가 아닙니다.

## 훈련·생활 추천

- 동일 대상의 식별된 분석에서 보통/높은 확신 개선 기록과 사람 개선 기록을 우선순위로 묶습니다. 근거가 없으면 일반 기초 연습이며 약점으로 단정하지 않습니다.
- 한국 날짜 28일에 팀·경기 요일을 우선합니다. 개인 연습은 15분·주 최대 3회, 기본 휴식 2일을 남깁니다. 기존 일정 자체가 주 6일 이상이면 추가 연습 없이 휴식 부족을 경고합니다.
- 준비 3분·본운동 9분·정리 3분 안에 세트·휴식이 포함됩니다. 4주 동안 양보다 관찰·방향 선택·경기 연결의 질을 바꿉니다.
- 공간·장비·부모 도움에 따라 혼자·공 없는 버전·실내 슈팅 대안을 제공합니다. 통증·높은 피로는 휴식, 나쁜 수면은 추가 개인 연습을 생략합니다. 미실천 벌점·몰아서 보충은 없습니다.
- 이동은 다른 연습·팀·경기와 겹치거나 주당 상한·휴식일을 깨면 반영하지 않습니다. 과제 ID와 날짜로 실천을 저장합니다.
- 하루 루틴은 학교·등교·놀이·식사·준비·씻기·가족 대화·수면을 배치합니다. 6~12세 수면 9~12시간 등 일반 권고를 참고하며 실제 수면 측정·진단을 하지 않습니다. 취침 전 60분 화면 내려놓기와 실수 후 다음 행동을 안내합니다.

별도 `growth-nutrition.js`가 실제 날짜 7일의 아침·점심·저녁·간식, 준비·대안·장보기를 만듭니다. 선택 동의한 알레르기·제한이 선호보다 우선하며 모르는 알레르기·중증·치료식은 자동 메뉴를 보류합니다. 급식은 실제 메뉴를 만들지 않고 보완합니다. 칼로리·감량·보충제·정량 수분 처방과 전문가 검수 주장은 없습니다. 재료 제외는 표시 성분·교차 접촉 안전 보증이 아닙니다.

공식 건강 문서 열람은 2026-10-16 중간 프록시 403으로 차단되었습니다. 최신 본문 미확인·개별 전문가 검토 없음 상태를 [출처 기록](health-sources.md)과 화면에 표시합니다.

## 동의·운영 범위

보호자 자기 확인, 영상별 업로드/AI 전송 동의, 식품 제한·컨디션 선택 동의를 구분합니다. 식사·컨디션은 영상 모델에 보내지 않습니다. AI 학습용 제공 동의는 기본 false이며 해당 수집 기능이 없습니다. 다른 아동의 초상·영상 권리를 촬영자 체크박스만으로 법적으로 해결했다고 주장하지 않습니다.

같은 계정만 열람합니다. 선수용/부모용 보기는 법정대리인 인증이나 별도 자녀 계정이 아닙니다. 선택 건강정보 동의 철회 시 식품 제한·컨디션 기록을 함께 지워야 합니다. 분석 동의 철회는 진행 작업을 취소하며 새 동의 전 재시도를 막습니다.

영상/관련 결과 삭제, 계정 삭제, 메타데이터 JSON 내보내기를 제공합니다. 앱 저장소 삭제가 외부 AI 제공자의 보관 정책까지 대신 보증하지는 않습니다. 이메일 인증·재설정·본인 확인·코치 ACL·푸시·운영자 화면·보관기한 자동 정리·독립 백업은 없습니다. 실제 클라우드 전체 동작, 선수 평가 정확도·성장 효과·수익성은 검증하지 않았습니다. 비용은 사용량 기반 추정이며 확정 가격이 아닙니다.

v1 localStorage/IndexedDB는 자동 이전하거나 삭제하지 않습니다. v2 계정의 빈 화면은 과거 기기 데이터 삭제를 뜻하지 않습니다.
