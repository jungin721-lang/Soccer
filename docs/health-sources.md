# 식사·수분·수면 안내의 출처와 확인 상태

이 모듈은 성장기 선수에게 사용할 수 있는 **일반 식사 구성 예시**입니다. 개인별 영양 처방, 질환 치료식, 전문가 검토를 완료한 식단으로 표시하지 않습니다. 칼로리·감량·보충제·개인별 정량 수분 처방은 생성하지 않습니다.

2026-10-16에 아래 공식 공개 페이지를 직접 요청했습니다. 실행 환경의 기본 네트워크는 `Operation not permitted`였으며, 네트워크 권한을 사용한 읽기 전용 요청도 모두 `Tunnel connection failed: 403 Forbidden`으로 차단됐습니다. 이는 해당 기관 웹사이트가 반환한 HTTP 403임을 확인한 것이 아니라 **중간 프록시가 연결을 거부한 결과**입니다. 공식 본문·최종 URL·개정일을 열람하지 못했으므로 `verifiedDate: null`, `status: unverified`, `checkedDate: 2026-10-16`으로 저장했습니다. 페이지가 현재 존재하거나 최신임을 검증했다고 주장하지 않습니다.

|---|---|---|---|
| USDA MyPlate | https://www.myplate.gov/life-stages/kids | 다양한 식품군의 식사 구성 | 프록시 403 · 본문 미확인 |
| CDC | https://www.cdc.gov/sleep/about/index.html | 나이에 맞는 충분한 수면·일정한 취침 루틴 | 프록시 403 · 본문 미확인 |
| AAP HealthyChildren | https://www.healthychildren.org/English/healthy-living/nutrition/Pages/Choose-Water-for-Healthy-Hydration.aspx | 규칙적인 수분 섭취 | 프록시 403 · 본문 미확인 |
| NIH Office of Dietary Supplements | https://ods.od.nih.gov/factsheets/Calcium-Consumer/ | 성장기 칼슘 공급원 정보 | 프록시 403 · 본문 미확인 |

AAP의 `Sports-Nutrition-and-Hydration-for-Young-Athletes.aspx` 경로도 같은 방법으로 차단되었습니다. 경로와 본문이 확인되지 않아 이 모듈의 출처 목록에서는 제외했습니다.

## 식사 생성 규칙

- 한국 날짜 기준 오늘 또는 지정한 실제 날짜부터 7일을 생성합니다. 날짜는 정오 UTC로 계산하여 호스트 시간대와 일광 절약 시간으로 하루가 바뀌는 문제를 피합니다.
- 아침·점심·저녁·간식마다 시점, 역할, 준비 방법, 대체 식품을 제공합니다. 음식량은 배고픔·포만감과 기존 지침에 맞춰 조정합니다.
- 주식·단백질 식품·채소·과일을 번갈아 배치합니다. 미리 양념된 고기, 육수, 빵, 복합 소스 등 숨은 성분이 많은 제품을 기본 메뉴로 쓰지 않습니다.
- 우유·달걀·밀·대두·땅콩·견과류·생선·갑각류/조개류의 영어 ID와 한국어 이름을 정규화하여 해당 재료를 제외합니다. 선호 음식보다 제외 규칙이 우선합니다. 채식·비건·돼지고기 제외·소고기 제외·글루텐 제외·유당 관련 제외도 적용합니다.
- 대두 제외 시 렌틸콩도 자동 대체 식품에서 제외합니다. 이는 렌틸콩이 대두라는 의미가 아니라, 이 단순 예시에서 다른 콩류로 자동 대체하지 않기 위한 보수적인 운영 규칙입니다.
- 인식하지 못하는 알레르기, 중증 알레르기, 치료식 등은 메뉴 생성을 중지하고 기존에 확인된 지침을 전문가와 검토하도록 안내합니다. 알레르기를 입력하지 않았다고 안전하다고 보지 않습니다.
- 제품별 알레르기·같은 제조시설·주방 도구·교차 접촉은 모듈이 검증할 수 없으므로 보호자와 조리 담당자의 확인이 필요합니다. 재료 제외는 알레르기 안전 보장이 아닙니다.
- 급식 이용 시 평일 점심의 실제 메뉴는 만들어내지 않습니다. 학교 식단·알레르기 정보를 확인하고 다른 식사에서 식품군을 보완하도록 안내합니다.
- 우유를 제외하면 임의로 다른 음료를 동등한 영양 대체품으로 추천하지 않습니다. 칼슘 공급원 선택은 별도 확인 대상으로 표시합니다.
- 훈련일이나 시각이 없으면 임의로 훈련 일정을 만들지 않고 조건부 안내만 제공합니다. 원본 영상의 플레이 수준에서 식사량·영양 결핍·섭식 문제를 추론하지 않습니다.

## 나중에 출처를 재검증할 때

연결이 가능한 환경에서 본문과 최신 개정일을 확인한 뒤 해당 문장이 실제로 뒷받침되는지 검토하고, 그때만 `verifiedDate`와 상태를 갱신합니다. 임상·개인화 수준을 높일 경우 전문가 검토와 콘텐츠 버전 기록은 별도 절차입니다. 현재 문서나 모듈은 그 검토가 이뤄졌다고 주장하지 않습니다.
