# 희찬의 다음 한 걸음 · 훈련 앱

버전: `1.1.0-sync` · 한국어 · 정적 HTML/CSS/ES modules. 기존 성장 앱·계정·서버와 분리된 `/training/index.html`입니다. 기존 저장소 변경은 보존했습니다.

## 실행과 배포 파일

```sh
cd /workspace/Soccer
npm run export:training
python -m http.server 8080 --directory .artifacts/training
```

위 정적 서버는 기기 모드 확인용입니다. 계정 동기화 검증은 `npm start`로 서버를 실행하고 `/training/index.html`을 엽니다. 위 서버는 내부 확인용입니다. 스마트폰에 공개할 HTTPS 링크가 생긴다는 뜻이 아닙니다. `.artifacts/training`의 **내용 전체**를 정적 호스팅에 배포합니다. 별도 준비한 `.artifacts/NEXT-STEP-training.zip`은 `index.html`이 최상위에 있는 동일한 묶음입니다. 개인 기록·계정 키·기존 앱 서버는 포함하지 않습니다. 따라서 이 프런트 ZIP만으로 계정 동기화는 동작하지 않습니다. 서버 포함 소스 묶음은 `.artifacts/NEXT-STEP-training-server-source.zip`이며 기존 Netlify 프로젝트의 Git 빌드와 같은 전체 소스 구성을 포함합니다. 원래 앱의 전체 배포는 `npm run export`를 사용하고, 새 페이지를 `/training/index.html`로 엽니다.

외부 폰트·이미지·분석 추적·AI API 호출은 없습니다. CSP `connect-src 'self'`로 같은 출처의 계정·훈련 API만 연결합니다. 로그인 전에는 계정 상태를 읽기만 하고 기기 기록을 자동 전송하지 않습니다. 출처 링크를 누르면 외부 기관 웹사이트로 이동하지만 훈련 기록을 URL에 넣지 않습니다. 앱 코드를 호스팅할 계정과 제공사의 무료 사용 한도는 별도이며 무제한을 보장하지 않습니다.

기존 Netlify 공개 주소는 열리지만 이번 동기화 작업에서 `/training/index.html`과 `/api/v2/status`는 모두 HTTP 404였습니다. Netlify 인증 변수·프로젝트 연결 파일도 없고, 사용자 화면에는 크레딧 소진으로 새 배포가 중지된 상태가 표시됐습니다. 배포 제한을 해제하거나 결제를 진행하지 않았습니다. GitHub Pages API도 현재 네트워크에서 접근되지 않았습니다. 새 공개 배포·실제 훈련 앱 HTTPS 링크는 아직 없습니다. 기존 사이트 링크를 새 앱의 링크로 안내하지 않습니다.

## 일정과 동작

- 월·수·일 아침/저녁을 계획할 수 있고 기본은 각 30분입니다. 10분·20분으로 줄일 수 있습니다.
- 준비·정리·명시적 휴식 구간이 전체 시간에 포함됩니다. 각 동작 구간에도 안내한 소량의 반복 뒤 충분히 쉬며, 남은 시간을 추가 세트로 채우지 않습니다.
- 일요일은 리프팅·가동성·휴식이며 저항·점프를 배정하지 않습니다. 피곤한 월요일도 같은 가벼운 구성으로 전환됩니다.
- 이미 활동이 많은 날은 10분으로 줄이며 통증이 있으면 운동을 시작하지 않고 휴식 선택만 기록합니다.
- 10분 정상 모드는 아침 리프팅·휴식, 저녁 쉬운 데드버그·휴식으로 압축해 여러 근력 동작을 짧은 구간에 몰아넣지 않습니다.
- 밴드는 튼튼한 지지대를 잡고 두 발목 위에 가벼운 루프를 두는 방식입니다. 밴드를 가구·문고리에 고정하지 않습니다. 그림은 자체 제작한 개념도이며 실제 자세 시범을 검증했다는 뜻이 아닙니다.
- 플랭크·투명의자는 짧고 쉬운 자세, 누운 코어는 데드버그부터 안내합니다. 줄넘기 한발·2단은 단계 확인 후 선택하고, 2단 연속 반복은 기본 과제에 넣지 않습니다.
- 연습 시작·기록은 실제 한국 날짜에서만 허용하며 다른 날짜는 미리보기입니다. 같은 시간대에 이미 기록이 있으면 추가 운동 대신 쉬도록 확인합니다.
- 개인 참고 기록은 편안하고 활동 과다·통증이 없는 수요일에 보호자 확인 후 한 종목만 주 1회 선택할 수 있습니다. 버티기는 바른 자세 20초까지의 참고 값이며 한계·탈진 측정을 요구하지 않습니다. 줄넘기·리프팅 참고 값은 최대 500회 입력 범위입니다. 이 한도는 달성 목표가 아닙니다.

## 타이머와 기록의 의미

타이머는 구간의 동작 **및 휴식** 시간입니다. 버티기 최대기록을 재는 타이머가 아닙니다. 시작 시각과 누적 경과를 저장하므로 일시정지는 제외하고, 새로고침·화면 복귀 시 실제 경과를 반영합니다. 경과는 현재 구간 시간으로 상한 처리하고 자동으로 다음 운동을 시작하지 않습니다. 화면을 닫거나 꺼도 알림이 실행된다고 보장하지 않습니다. 실제 세션 시간도 구간별 경과 합계이며 체크 항목은 수동 확인입니다. 시간표를 마쳤다고 모든 운동을 수행했다는 뜻이 아닙니다.

## 기기 저장과 개인정보

로그인 전에는 IndexedDB `next-step-training-v1`의 `main` 키에 별명·설정·연습 기록·개인 참고 기록·진행 중 타이머를 저장합니다. 로그인 후에는 설정·완료 기록·참고 기록을 서버에 저장하고 기기 타이머는 `account:<userId>` 키로 계정마다 분리합니다. 계정 타이머 캐시에 완료 기록이나 컨디션은 저장하지 않습니다. 공용 기기의 같은 브라우저 사용자에게는 별도 로그인으로 보호되지 않으므로 사용 후 삭제하거나 개인 브라우저를 사용합니다. 같은 주소에서 같은 계정으로 로그인하면 아래 절차로 자동 동기화됩니다. 같은 브라우저의 여러 탭이 동시에 저장할 때 revision이 다르면 덮어쓰기를 거절하고 새로고침을 안내합니다.

컨디션은 초기에는 화면에서만 사용합니다. 보호자가 저장 동의한 경우 완료 기록에 편안함·통증을 저장하고 백업에도 포함합니다. 동의 철회 시 기존 컨디션 필드를 삭제합니다. 진행 중 타이머에는 컨디션을 넣지 않으며 새로고침한 세션의 컨디션을 추정해 저장하지 않습니다.

백업은 사용자 선택으로 JSON 파일을 다운로드합니다. 진행 중 타이머는 제외합니다. 복원은 5MiB 이하 파일을 검증하고 내용을 먼저 보여 준 뒤 확인해야 적용합니다. 기본은 현재 모드(기기 또는 계정)의 기록 병합이며 별명·설정 가져오기와 민감정보 가져오기는 별도 선택입니다. 계정 모드에서 확인하면 서버에도 전송됩니다. 같은 ID의 다른 기록이나 주 1회 제한을 어기는 병합은 전체 중단하고 기존 자료를 보존합니다. 손상된 저장소는 자동 초기화하지 않습니다. 브라우저 데이터 삭제·시크릿 모드 종료·기기 분실에 대비해 비공개 백업을 별도로 보관해야 합니다.

GPT 대화·메모리에 직접 기록을 쓰는 연결은 구현하지 않았습니다. 일반 웹앱이 개인 ChatGPT 메모리를 데이터베이스처럼 읽고 쓰는 공식 연결은 이 작업에서 확보하지 못했습니다. OpenAI API의 서버 저장 기능은 개인 ChatGPT 메모리와 별개이며, API 키·외부 데이터 전송을 요구하는 대안을 자동으로 추가하지 않았습니다. 공식 개발자 문서 접근도 현재 403으로 막혔으므로 새 공식 기능 전체를 검증했다고 주장하지 않습니다.

## 계정 자동 동기화 사용법 · v1.1

1. 서버 함수까지 포함한 저장소를 **하나의 Netlify 프로젝트**에 배포합니다. Node 24, 잠금파일 설치, `npm run export`, 공개 폴더 `.artifacts/site`, 함수 폴더 `netlify/functions`를 사용합니다. 기존 `netlify.toml`이 이 구성을 선언합니다. 별도 유료 AI·새 외부 저장 서비스는 추가하지 않았습니다. Netlify의 기존 Blobs 바인딩 `next-xi-growth-v2`를 사용하며 호스팅·저장 사용 한도는 별도입니다.
2. PC와 스마트폰에서 같은 출처의 `/training/index.html` → **설정·백업** → 같은 보호자 계정으로 로그인합니다. 기존 축구 앱 계정도 사용합니다. 새 계정은 성인 보호자 동의로 가입하며 본인 인증·비밀번호 재설정은 구현하지 않았습니다.
3. 로그인하면 서버 기록을 엽니다. 기존 기기 자료는 그대로 별도 유지하며 **이 기기의 기존 기록을 계정으로 가져오기**에서 동의 후 합칠 수 있습니다. 별명·설정과 컨디션 가져오기는 각각 선택합니다. 컨디션 전송에는 계정의 저장 동의도 필요합니다.
4. 설정·완료한 연습·개인 참고 기록은 서버에 저장하고 다른 기기에서 약 5초 간격으로 읽습니다. 탭 복귀·창 포커스·네트워크 복구 때도 확인합니다. 폼 입력 중·저장 중·가져오기 확인 중에는 자동 화면 교체를 보류합니다.
5. 진행 중 타이머는 기기별입니다. 다른 기기의 타이머를 원격 조작하거나 이어받지 않습니다. 각 기기에서 마친 기록만 같은 계정에 모입니다.

서버는 인증된 사용자 ID로만 `training/<userId>`를 읽고 쓰며 URL의 다른 사용자 ID는 사용하지 않습니다. API 응답은 비공개·캐시 금지입니다. PUT의 revision을 원자적 조건부 갱신으로 검사합니다. 클라이언트는 화면의 원본·변경 의도·서버 최신 데이터를 비교하여 서로 다른 설정 필드와 독립된 기록 추가를 합칩니다. 같은 항목의 다른 값과 같은 주의 참고 기록 중복은 거절하고 입력을 보존합니다. 동시에 추가된 서버 기록은 오래된 목록으로 덮어쓰지 않습니다.

오프라인에서는 서버 저장 성공으로 표시하지 않으며 입력·타이머를 유지해 연결 후 명시적으로 다시 저장하도록 안내합니다. 훈련 종료 ID는 타이머 시작 때 생성한 UUID로 고정합니다. 서버가 저장한 뒤 응답만 유실된 경우 재시도는 이미 저장한 같은 훈련을 인식하고 중복 기록이나 경과시간 덮어쓰기를 만들지 않습니다. 세션 만료·계정 변경 응답을 받으면 계정 화면을 닫고 원래 기기 자료로 돌아갑니다. 로그아웃도 동일하며 기기의 원본 기록을 삭제하지 않습니다.

계정 모드의 삭제는 현재 표시된 계정 훈련 자료를 삭제하며 다른 기기에 반영합니다. 동시에 추가된 기록은 보존될 수 있습니다. 원래 기기 자료·이미 내보낸 백업은 별도입니다. 기존 메인 앱에서 계정 전체 탈퇴를 실행하면 훈련 데이터도 내용 없는 삭제 표식으로 바꿔 진행 중 요청이 복원하지 못하게 합니다.

검증: `npm run test:training-sync`는 실제 로컬 서버와 독립 1440px PC·390px 모바일·320px 다른 계정 세션에서 가입·로그인, 자동 설정/완료 기록 반영, 명시적 자료 이전·원본 보존, 동시 필드·기록 병합과 충돌 보존, 타이머 분리, 오프라인 재시도, 성공 응답 유실 후 중복 방지, 만료·재로그인·새로고침, 계정 격리·로그아웃 복구를 확인합니다. 실제 Netlify 배포와 다른 기기 하드웨어에서의 검증은 아직 수행하지 않았습니다.

## Netlify 배지와 화면 겹침 방지

공개 배지 iframe(`#nl-badge-frame`)이 실제로 나타난 경우에만 하단에 112px와 기기 안전 영역만큼 공간을 둡니다. 하단 메뉴·알림·모달·대화상자도 배지 위로 이동하고 마지막 콘텐츠까지 스크롤할 수 있습니다. 배지 자체를 숨기거나 클릭을 막지 않습니다. 배지가 없으면 기존 간격을 유지합니다. 배지의 펼쳐진 상세 패널은 사용자가 연 오버레이이며, 이 수정의 검증 대상은 닫힌 배지 버튼입니다. CSS `:has()`를 지원하는 최신 브라우저 기준입니다.

검증: `python tests/netlify-spacing-browser.py`는 320·390·900·1024·1280px 폭에서 실제 앱 스타일과 표시·클릭 가능한 배지 모형을 사용해 메뉴·마지막 버튼·알림·확인 창의 겹침 방지 및 배지 부재 시 간격 복원을 확인합니다. 실제 공개 페이지에는 Netlify 재배포 후 적용됩니다.
