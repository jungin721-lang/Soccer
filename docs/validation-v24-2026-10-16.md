## 검증하지 못한 조건

개발 환경에 `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`의 실제 값이 없습니다. 실제 무료 계정 구독 조회, Cloudflare 추론 성공, 여러 이미지의 실제 서빙 제한과 영상 속 등번호 정확도는 검증하지 못했습니다. 실제 사용자 원본 전체를 분석하거나 모든 11번 출현을 검출했다고 주장하지 않습니다.

1초 간격 정지화면과 구간별 최대 4개 JPEG가 AI 입력이며, 동영상의 모든 프레임을 연속 추적하는 기능이 아닙니다. 짧은 출현·흐리거나 가려진 등번호를 놓칠 수 있습니다. 영상 근거를 위해 보관하는 MP4는 연속 영상입니다. 물리 iPhone/Android, 1GiB 이상 원본의 처리 성능, 장시간 Netlify 누적 비용·무료 할당량은 이번 로컬 합성 검사로 검증하지 않았습니다.

운영자의 무료 계정 연결 후 앱의 합성 이미지 연결 점검부터 실행할 수 있습니다. 연결 설정과 공식 출처는 [무료 분석 안내](free-cloudflare-analysis.md)를 참고하세요. 개발용 클라우드 설정 초안 저장은 실행 환경 적용·게시나 Netlify Production 비밀 설정을 대신하지 않습니다.
