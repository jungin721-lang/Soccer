# 희찬이의 축구 성장 훈련: 운영 화면 작업 기록

## 실제 운영 원본과 저장 방식

2026-10-28 한국 시간에 `https://earnest-shortbread-008d93.netlify.app/`의 응답을 확인했다. 사용자가 캡처한 밴드 발 뻗기·줄넘기 화면이 포함된 단일 HTML 앱이었으며, 브라우저의 `localStorage` 키 `heechans-football-growth-v1`에 설정·운동 기록·세션 기록을 저장하고 있었다. 확인 당시 `/training/index.html`은 HTTP 404였으므로, 저장소에 있던 별도 훈련 페이지의 수정만으로 해당 운영 화면이 바뀐다고 볼 수 없다.

현재 운영 원본의 데이터는 기기와 브라우저별로 분리되어 있다. 로그인·서버 저장이나 자동 동기화는 원본에서 확인되지 않았다. 같은 출처에서 기존 키와 기존 데이터 형식을 보존해야 그 기기의 이전 기록을 읽을 수 있다. 시크릿 모드 종료·브라우저 데이터 삭제·기기 분실은 기기 기록의 손실로 이어질 수 있다. 데이터 이전과 동기화는 별도 기능이며 구현과 실제 검증 전에는 제공한다고 말하지 않는다.

기존 Netlify 프로젝트의 운영 배포는 확인 당시 Netlify Drop으로 게시한 2026-10-13 배포였다. 저장소의 전체 사이트를 그대로 게시하면 사용 중인 화면을 다른 앱으로 대체할 수 있으므로, 실제 운영 화면과 저장소의 기능·경로를 비교하고 기존 기기 저장 데이터의 호환성을 검사한 후 배포해야 한다. Netlify가 응답에 동적으로 삽입한 공개 배지 스크립트는 복사본에 중복 포함하지 않으며, 배지가 표시될 경우 메뉴와 버튼을 가리지 않도록 공간을 확보한다. GitHub 병합이나 미리보기 성공은 운영 배포 성공을 뜻하지 않는다. 최신 Netlify 크레딧·사용량은 인증된 관리 화면에서 별도 확인해야 한다.

## 소아·청소년 활동 지침 확인

확인일: **2026-10-28, 한국 시간**. 아래 원문은 각각 HTTP 200으로 조회했다.

- [미국 질병통제예방센터(CDC), Child Activity: An Overview](https://www.cdc.gov/physical-activity-basics/guidelines/children.html): 6–17세는 매일 중강도 이상의 신체활동 60분 이상을 권고하며, 주 3일 이상의 근육 강화 및 뼈 강화 활동을 포함하도록 설명한다. 학교 활동을 비롯한 일상의 신체활동 전체를 고려한다. 또한 어린이에게 별도의 정식 근력 훈련 프로그램이 보통 필요한 것은 아니라고 설명한다.
- [세계보건기구(WHO), Physical activity](https://www.who.int/news-room/fact-sheets/detail/physical-activity): 모든 신체활동이 의미 있으며, 활동이 전혀 없는 것보다 적은 양이라도 하는 것이 낫다고 안내한다. 아동·청소년에게 신체활동은 뼈 건강과 운동 발달 등에 도움이 될 수 있다고 설명한다.

CDC의 60분은 하루 전체 활동에 관한 일반적인 공중보건 권고다. 이 앱에서 아침과 저녁에 각각 30분을 반드시 채워야 한다는 뜻이 아니며, 축구팀 훈련·경기·체육수업·걷기·놀이 등을 함께 고려한다. 통증이나 피로가 있으면 쉬고, 빠진 운동을 몰아서 하지 않는다. 이 자료는 특정 아동에 대한 의학적 처방이나 이 앱의 동작별 시간·횟수·세트 수를 검증한 평가가 아니다. 보호자와 지도자가 자세와 당일 컨디션을 살피고 필요한 경우 의료 전문가와 상의한다. 국가대표 선발, 키 성장 또는 특정 운동 결과를 보장하지 않는다.

기존에 인용된 AAP의 `Strength-Training-by-Children-and-Adolescents.aspx` 주소는 이번 확인에서 HTTP 404였으므로 내용을 확인한 근거로 제시하지 않는다.
