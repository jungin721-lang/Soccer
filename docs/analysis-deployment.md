# NEXT XI v2 · Netlify 배포와 서버 설정

v2는 계정·원본 저장·서버 백그라운드 분석을 사용합니다. **정적 ZIP을 Netlify Drop에 올리는 것만으로는 동작하지 않습니다.** 기존 프로젝트의 Git 연결을 유지하고 서버 함수가 포함된 저장소를 빌드합니다. 새 프로젝트는 주소와 저장소가 달라질 수 있습니다.

## 저장소에 지정된 배포 구성

| 항목 | 값 |
|---|---|
| 기존 프로젝트 | courageous-entremet-c8f097 — 실제 계정의 프로젝트·공개 주소가 기준 |
| 저장소·브랜치 | jungin721-lang/Soccer · next-xi-download-20261016 |
| Node·설치 | 24 이상 · 잠금파일 기준 npm ci |
| 빌드 | npm run export |
| 공개 폴더 | .artifacts/site |
| 함수 폴더 | netlify/functions |
| 저장소 | Netlify Blobs next-xi-growth-v2 |

`netlify.toml`, `package-lock.json`, 서버·프런트엔드 소스가 함께 필요합니다. export는 프런트엔드를 복사하며, 생성된 `NEXT-XI.html`은 독립형 앱이나 서버 없는 로그인 대안이 아닙니다. 기존 v1 정적 파일은 v2 서버를 대체하지 않습니다.

| 함수 파일 | 역할 |
|---|---|
| growth-api.mjs | /api/v2/* — 계정·워크스페이스·업로드·원본·작업 API |
| growth-worker-background.mjs | 서버 FFmpeg·AI 요청·체크포인트·계속 실행 |
| growth-recovery.mjs | */10 * * * * — 10분마다 만료·대기 작업 복구 |

이전 `/api/analysis`는 현재 v2 경로가 아닙니다. v2는 개발용 분석 코드를 입력하는 구 화면을 사용하지 않습니다.

FFmpeg 실행파일을 백그라운드 함수에 포함하도록 설정했습니다. Netlify의 백그라운드 최대 15분을 전제로 작업당 8분 예산을 적용하고, 완료하지 못하면 다음 실행으로 넘깁니다. 실제 클라우드의 함수 포함·권한·실행 제약·복구는 전체 검증을 마치지 않았습니다.

## 환경변수

서버 키는 Netlify Environment variables의 Functions 런타임·Production에 적용합니다. HTML·브라우저·GitHub 파일·채팅에 넣지 않습니다. 키가 설정되지 않은 경우에만 소유 계정에서 설정이 필요합니다. 기존 서버 키 바인딩을 사용할 수 있습니다.

| 이름 | 용도·기본값 |
|---|---|
| SOCCER_AI_API_KEY | OpenAI 서버 키. 기존 OPENAI_API_KEY로 대체 가능 |
| SOCCER_AI_MODEL | 선택 · gpt-4.1-mini |
| SOCCER_FFMPEG_PATH | 선택 · 기본 포함 바이너리 대신 쓸 서버 실행파일 |
| SOCCER_MAX_DAILY_JOBS | 선택 · 전체 서비스 KST 날짜별 새 분석+재시도 30회 |
| SOCCER_MAX_USER_DAILY_JOBS | 선택 · 계정별 하루 새 분석 3회 |
| SOCCER_MAX_USER_ACTIVE_JOBS | 선택 · 계정별 동시 진행 2개 |
| SOCCER_MAX_JOB_DAILY_ATTEMPTS | 선택 · 작업별 최초 실행 포함 하루 시도 3회 |

계속 실행·정기 복구는 새 유료 작업 예약으로 세지 않습니다. 작업 수 상한은 정확한 원화 과금 상한이 아닙니다. 분석 길이·이미지·모델·저장·전송량에 따라 실제 비용이 달라집니다. ChatGPT 구독과 API 이용료는 별개입니다.

v2는 로그인 세션과 서버 간 한시 작업 토큰을 사용합니다. 일반 이용자에게 API 키나 `SOCCER_ANALYSIS_ACCESS_CODE`를 요구하지 않습니다. Netlify 저장소·배포 출처는 런타임 바인딩을 사용하며 관리 토큰을 앱에 하드코딩하지 않습니다. worker의 내부 원본 요청은 Netlify가 제공하는 *.netlify.app 배포 출처를 사용합니다.

## 배포 결과를 읽는 방법

기존 프로젝트의 Git 연결·브랜치·netlify.toml로 빌드합니다. 배포 로그에 세 함수와 FFmpeg가 포함되었는지가 실제 반영의 기준입니다. 현재 시작 화면은 로그인 페이지이며 메타 버전은 `2.0.0-growth-workspace`입니다. 저장소 변경 완료를 공개 사이트 업데이트 완료로 표시하지 않습니다.

공개 주소의 **GET /api/v2/status**는 설정 확인 JSON을 반환합니다.

```json
{"available":true,"reason":"ready"}
```

**ready는 서버 설정이 있다는 뜻입니다.** API 키 유효성·잔액·모델 접근·Blobs 쓰기·FFmpeg 실행·작업 완료를 입증하지 않습니다. 이 개발 환경에는 실제 키가 없어 유료 AI 호출과 Netlify 전체 경로 검증은 미완료입니다.

사용자는 **보호자 가입 → 원본·색상·등번호 등록 → 동의 후 업로드 → 서버 분석 → 경기 결과**로 이용합니다. 업로드 중에는 화면과 네트워크를 유지합니다. 서버가 받은 지점은 보관하며 같은 기기에서 같은 파일을 다시 고르면 이어 올립니다. 업로드 후에는 브라우저를 닫아도 서버 분석이 지속되도록 설계했습니다.

## 원본·작업 운영

- 원본당 최대 2 GiB, 전송 조각 2 MiB입니다. 파일럿 계정은 전송 중을 포함해 영상 10개·보관 6 GiB·중단/진행 업로드 3개 상한을 적용합니다. 모든 스마트폰에서 2 GiB 전송을 실측한 것은 아닙니다.
- 인증된 원본 바이트 범위 응답은 기본 최대 4 MiB입니다. 더 큰 원본의 무범위 GET은 413, HEAD는 전체 크기를 반환합니다. 플레이어·FFmpeg가 후속 구간을 요청하며 FFmpeg는 조기 연결 종료 뒤 재연결하도록 설정했습니다.
- 브라우저 코덱 지원은 남아 있습니다. HEVC/MOV의 전 기기 재생용 트랜스코딩은 없습니다. 서버 JPEG 추출과 사용자 브라우저 재생은 별개입니다.
- 최대 120표본에서 지정 선수를 찾고 최대 6개×12초 구간을 분석합니다. 원본은 앱 서버에, 필요한 JPEG는 OpenAI API로 전송합니다. 영상 속 다른 인물도 JPEG에 포함될 수 있습니다.
- 체크포인트를 저장하고 취소·실패·선수 확인 보류를 완료와 구별합니다. 복구 스케줄러가 작동하지 않으면 이어서 실행이 지연될 수 있습니다.
- 영상·계정 삭제 API가 관련 앱 저장소를 제거합니다. 중단 업로드·오래된 세션·보관기한의 자동 정리, 독립 백업, 운영자 관리 화면은 아직 없습니다.

## 오류·상태 안내

| 상태 | 의미 |
|---|---|
| /api/v2/status가 404 또는 HTML | 서버 함수 누락·이전 배포·다른 프로젝트 주소 가능 |
| missing_credentials / invalid_key_format | 서버 키 누락 또는 붙여넣기 형식 오류. 키 값을 노출하지 않고 서버 설정에서 수정 |
| 다른 기기 기록이 없음 | 같은 배포 주소·계정인지 구분. v1 기기 기록은 자동 이전되지 않음 |
| 업로드 완료·분석 시작 실패 | 원본 재업로드 불필요. 서버 설정 후 해당 경기에서 재실행 |
| 원본 재생 실패 | 브라우저 코덱·파일 손상 가능. 서버 분석 가능 여부와 별개 |
| 공급자 인증·모델 접근 오류 | 실제 키·모델 권한 문제. ready 응답만으로 배제할 수 없음 |
| 429 / 일일·동시 작업 한도 | 앱 운영 상한 또는 공급자 이용 한도. 완료 결과와 원본은 유지 |
| 선수 확인 보류 | 표본에서 지정 선수를 확인하지 못함. 임의 점수·장면 생성 없음 |
| AI 설명은 있고 능력 지도는 비어 있음 | 사람의 근거 평가가 없으면 관찰 부족. AI 관찰을 종합 점수로 환산하지 않음 |

계정은 보호자의 자기 확인이며 이메일·법정대리인 본인 인증은 없습니다. 선택 건강정보 동의가 없으면 알레르기·식사 제한·컨디션을 저장하지 않습니다. 분석 동의 철회는 진행 작업을 취소하고 새 동의 전 재시도를 막습니다. AI 학습용 제공은 기본 미동의이며 현재 수집하지 않습니다.

코치 공유 ACL·웹 푸시·비밀번호 재설정·자동 보관 운영·전문가 검토·법률 검토가 완료된 서비스로 표시하지 않습니다. 건강 자료의 최신 본문 열람은 프록시 403으로 막혀 [출처 기록](health-sources.md)에 미확인 상태로 남아 있습니다.

## 검증·이전 버전

현재 검증 명령은 `npm run check`, `npm test`, `npm run export`, `python tests/growth-browser.py`입니다. 실제 H.264 MP4 처리 테스트가 있지만 AI 응답과 외부 저장 서비스는 모의 검증을 포함합니다. 실제 선수 식별 성능·성장 효과·API 결제 성공은 테스트 통과로 대체하지 않습니다.

v1 localStorage·IndexedDB는 자동 삭제하거나 이관하지 않습니다. v2는 새 계정의 서버 공간을 사용합니다. 같은 도메인이라도 과거 기기 데이터가 새 계정에 자동 표시되지 않습니다.
