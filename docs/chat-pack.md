# 대용량 영상의 채팅용 자료 준비 — v2.2

스마트폰에서 원본이 커 채팅 첨부에 실패하는 경우 `/chat-pack.html`을 사용합니다. 로그인·유료 API·서버 업로드 없이 기기에서 JPEG와 ZIP을 생성합니다. 원본을 변경하거나 다른 서비스에 자동 전송하지 않습니다.

## 사용 흐름

1. 사진·파일 앱에서 원본을 선택합니다.
2. 유니폼 색·등번호·나이를 확인하고 공유 권한 동의를 선택합니다. 초기값은 남색·11번·11세입니다.
3. ‘작은 분석자료 만들기’를 누른 뒤 화면을 유지합니다. 직접 장면을 찾거나 시작 시간을 입력하지 않습니다.
4. 완성한 ‘ZIP 다운로드’ 또는 ‘이미지 저장’으로 자료를 저장하고, 사용자가 채팅에 직접 첨부합니다. 지원하는 브라우저에서는 ‘이미지 공유’도 제공합니다.
5. 지정 선수가 보이지 않으면 ‘다른 시점 자료 만들기’로 시간표본 위치를 바꿉니다. 3개 묶음을 순환하며, 짧은 영상은 같은 시점이 될 수 있습니다.

## 실제 범위

| 항목 | 동작 |
|---|---|
| 입력 | 최대 8 GiB 파일 정보 검증. 실제 처리 가능 여부는 기기·코덱·탐색 지원에 따름 |
| 원본 읽기 | Blob URL과 브라우저 영상 탐색 사용. 원본 전체를 JavaScript ArrayBuffer로 읽지 않음 |
| 시간표본 | 최대 6개 시간 구간, 각 최대 3초 범위의 최대 6프레임, 총 최대 36프레임 |
| 결과 | 시각·대상·한계가 표시된 JPEG 최대 6장, manifest.json, README.txt |
| 크기 | JPEG 화질·크기 조정 후 ZIP 전체 8 MiB 이하, 이를 넘으면 성공으로 표시하지 않음 |
| ZIP | STORE 방식·CRC32·UTF-8 파일명. JPEG는 이미 압축된 파일임 |
| 개인정보 | 영상 파일명·프로필 이름·건강·식사 기록은 자료에 넣지 않음. 이미지 속 얼굴과 장면은 포함될 수 있음 |
| 전송 | 페이지는 원본·이미지를 서버/API에 전송하지 않음. 생성 뒤 사용자가 공유할 앱과 파일을 직접 선택 |
| 중단 | 취소·화면 이탈·브라우저 종료 시 서버 작업으로 이어지지 않음. 원본은 보존하고 재선택·다시 생성 가능 |

이는 **자동 시간표본 준비**입니다. 선수 식별·등번호 인식·추적·AI 평가를 실행하지 않습니다. 중요한 플레이나 대상 선수가 표본에 없을 수 있습니다. 연속 움직임·공의 궤적·전체 경기 능력·전국 순위는 정지 화면으로 확정할 수 없습니다. 표본에 선수가 명확히 확인될 때에만 채팅에서 보이는 행동을 피드백할 수 있습니다. 채팅 결과를 앱의 검증된 분석 결과로 자동 저장하지 않습니다.

이 기능은 기존 OpenAI 자동 분석의 결제 상태를 바꾸지 않습니다. 준비 과정의 API 호출은 없지만 채팅 첨부·사용 한도와 다운로드·공유 지원은 사용하는 서비스·브라우저를 따릅니다.

## 검증 명령

Node 24·FFmpeg, Python의 Playwright·Pillow, `/usr/bin/chromium`이 필요합니다. 공개 HTTPS에 대한 검사는 `CHAT_PACK_BASE_URL`로 지정할 수 있으며 어떤 경우에도 API·외부 이미지 전송을 실행하지 않습니다.

```sh
npm run check
npm test
npm run test:chat-pack
```

실제 H.264 합성 원본으로 브라우저 탐색·화면 추출·ZIP CRC·시간표본·다운로드·개인정보 제외·API 전송 없음·취소·재시도를 확인합니다. 실제 유소년 영상, 물리 iPhone·Android, HEVC 및 실제 8 GiB 파일의 모든 조건을 검증한 것은 아닙니다.
