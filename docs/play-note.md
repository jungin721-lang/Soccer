## 새 앱의 영상 삭제 정책

새 UI는 촬영 권한, Cloudflare 장면 전송, 분석 후 영상 삭제 동의를 각각 받습니다. `/uploads`에 명시적인 `deleteVideosAfterAnalysis:true`를 보낸 새 영상만 `report_only` 정책으로 등록합니다. 이전 앱의 영상 정책은 소급 변경하지 않습니다.

1. MP4 파일의 브라우저 메타데이터·재생 가능 여부를 검사합니다. 새 앱 시험 한도는 100MiB, 10분입니다. 서버도 파일명/크기와 FFmpeg로 읽은 길이를 검사합니다. 이는 호스팅의 무료 용량을 뜻하지 않습니다.
2. 최대 2MiB 조각을 전송하며 서버가 수신을 확인한 바이트 수로 진행률을 표시합니다. 같은 계정·기기에서 같은 파일로 이어 올릴 수 있습니다. 업로드가 끝났다고 분석 완료로 표시하지 않습니다.
3. 서버가 분석을 완료하고 텍스트 결과를 다시 읽어 일치함을 확인한 경우에만 원본·근거 영상 삭제를 시작합니다. 추가 MP4 인코딩·저장을 하지 않습니다.
4. 선수 미발견으로 정상 완료된 경우에도 그 결과를 보존하고 영상을 정리합니다. 실패·한도 대기·취소는 자동 삭제하지 않고 재시도·직접 삭제를 제공합니다. 자동 보관 만료 청소는 아직 구현하지 않았으므로 처리되지 않은 영상이 무기한 안전하게 정리된다고 안내하지 않습니다.
5. 원본과 근거 영상의 모든 저장 키를 삭제하고 다시 목록을 확인한 뒤 삭제 날짜·0바이트 저장 요금을 반영합니다. 중간에 끊기면 체크포인트와 작업 잠금으로 재개합니다. 결과 검증 실패는 영상 삭제를 허용하지 않습니다.
6. 완료 후 피드백·원본 시각·훈련·기본 메타데이터만 남습니다. 영상 재생·재분석은 불가능하며 필요하면 기기의 원본을 다시 업로드해야 합니다. 기기 사진첩 원본은 수정하지 않습니다.

‘삭제 완료’는 앱 서버 저장소의 객체 삭제와 API 재생 불가를 뜻합니다. Netlify·Cloudflare의 물리 매체·백업·외부 AI 로그 보관·파기 시점까지 보장하지 않습니다. 실패·중단 업로드는 목록에서 직접 삭제해야 합니다.

## 실제 분석 연결과 개인정보

이 환경에 Cloudflare 인증 변수는 없습니다. 기존 Netlify 사이트 환경변수 메타데이터 조회는 401이었으므로 서버에 이미 있는 비밀 값을 읽거나 ‘없다’고 단정하지 않았습니다. 배포된 새 앱의 연결 상태를 먼저 확인하고 기존 바인딩을 재사용합니다. `missing_credentials`가 확인되는 경우에만 `CLOUDFLARE_ACCOUNT_ID`와 `CLOUDFLARE_API_TOKEN`을 배포 프로젝트의 Functions 비밀 설정에 연결합니다. 값은 채팅·GitHub에 넣지 않습니다.

실제 공급자 연결 성공은 새 앱의 **합성 이미지로 무료 연결 점검**에서 확인합니다. 이 점검은 사람이 없는 합성 이미지이며 성공해도 실제 경기 식별 정확도나 경기 전체 분석의 성공을 뜻하지 않습니다. 현재 실제 무료 분석 성공을 확인하지 못했습니다. 기본 UI는 미연결 시 업로드도 보류하고 이유를 보여 줍니다.

피드백은 동일한 유니폼·번호가 확인되는 프레임 표본에 근거한 AI 초안입니다. 연속 추적·모든 플레이·얼굴 인식·실명 식별·건강·잠재력·전국 순위 기능은 없습니다. 원본 시각과 관찰·해석의 한계를 표시하며 재생 파일을 삭제한 뒤에는 기기 원본의 해당 시각을 직접 확인해야 합니다. 사용자 수동 선수 위치 지정·오인식 정정 도구와 실제 경기 정확도 측정은 아직 구현·검증하지 않았습니다.

훈련은 기존 근거 기반 규칙을 재사용합니다. 관찰 근거가 없으면 일반 기본 연습으로 구분하고 준비·동작·정리·쉬운 단계를 안내합니다. 전문 코치·의료 처방이 아니며 기존 운동 지침 대조·아동별 검토 제한도 그대로 남습니다.
