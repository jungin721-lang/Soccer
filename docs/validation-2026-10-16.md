# v2 검증 기록 — 2026-10-16

검증 환경: Node 24.19, Linux Chromium / Playwright, FFmpeg. 실제 iPhone·Android 기기 또는 Safari로 시험한 결과가 아닙니다.

- `npm run check`: 모든 JavaScript 문법 검사 통과.
- `npm test`: 175개 테스트 통과. 계정 격리, 비밀값 제외, 동의, 저장 용량/분석 제한, 원본 이어 올리기, 범위 재생, 재시작, 분석 체크포인트, 취소·삭제·복구, 날짜·회복·알레르기·비교 규칙 포함.
- `python tests/growth-browser.py`: 320/390px에서 가입, 선수 설정, 실제 H.264 MP4 업로드, 일시적 503 후 재시도, 바이트 일치, 재생, 실천·컨디션, 새로고침·로그인 복원, 계정별 비공개 접근 통과. 테스트용 분석 응답으로 두 실제 영상의 비교·근거 재생·훈련 연결·미저장 메모 복원을 추가 확인.
- 보호자 세션이 종료된 뒤에도 서버 작업이 인증된 HTTP Range로 실제 원본을 읽고 결과를 저장했습니다. 4KB로 강제 분할한 범위 응답의 재연결과 저프레임 영상 마지막 시각을 확인했습니다. 정상 MP4·WebM은 디코딩됐고 MP4로 위장한 HLS의 외부 참조 요청은 0건이었습니다.
- 공식 `@netlify/zip-it-and-ship-it` 16.3.0에서 v2 API, background 실행 모드, Node 24, 10분 예약 복구를 인식했습니다. 워커 ZIP 약 32.5MB/해제 약 81.1MB에 실행 권한이 있는 FFmpeg가 포함됐으며 번들을 풀어 실제 바이너리 실행을 확인했습니다. 이는 Netlify 계정에서 배포·실행한 검증과 다릅니다.

**AI 응답은 테스트에서 모의 처리했습니다.** 실제 유소년 선수 식별 정확도, 피드백의 코칭 타당성, 훈련 효과를 검증하지 않았습니다. 자동 탐색은 표본과 선택한 구간을 분석하며 전수 연속 추적이 아닙니다. 사람의 행동 근거가 없는 능력 점수와 경기 간 수치 변화는 보류합니다.

실제 OpenAI `/v1/models`에 인증 없이 연결하면 예상한 401(Missing bearer authentication)이 반환됐습니다. 네트워크 도달성만 확인한 것이며 이 개발 환경에 실제 서버 API 키가 없어 유효한 키의 모델 호출 성공은 확인하지 못했습니다. 사용자의 기존 Netlify 비밀값에는 접근하지 않았습니다.

공개 Netlify 주소와 공식 건강·Netlify 문서 요청은 중간 네트워크 프록시의 CONNECT 403으로 차단됐습니다. 게시 완료, 실제 Netlify Blobs 연결, 실제 AI 호출, 공식 건강 문서 최신 본문·전문가 검토는 검증 완료로 표시하지 않습니다. 보호자 확인은 자기 확인 방식이며 이메일 검증·비밀번호 재설정·코치 초대·푸시 알림·자동 보관기한 정리는 아직 없습니다.

v1 기기 내 데이터는 자동 이전하지 않으며 삭제하지 않았습니다. 테스트 계정과 원본은 임시 저장소를 사용했고 배포 ZIP에서 `.data`, `.env`, `node_modules`, 테스트 결과 및 Git 메타데이터를 제외합니다.
