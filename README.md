# NEXT XI

남색 유니폼 11번 유소년 선수의 원본 영상을 등록하고, 앱이 선수를 탐색해 분석 구간을 자동 선택하는 웹앱입니다. v1.3에서는 시작 시간을 입력하거나 영상을 일시정지할 필요가 없습니다.

## 실제 사용 흐름

1. 스마트폰의 사진·파일 앱에서 원본 영상을 등록합니다.
2. **남색 11번 자동 분석**을 누르고 전송에 동의한 뒤 분석 이용 코드를 입력합니다.
3. 앱이 영상의 처음부터 끝에 걸친 일정 간격의 표본을 준비합니다. 약 5초 간격이며 긴 영상은 전체 시간대를 균등하게 최대 120개 시점으로 나눕니다.
4. 서버가 남색 상의와 등번호 11이 함께 보이는 표본을 찾습니다. 식별이 불확실하면 기권합니다.
5. 앱이 확인 시점 주변의 최대 12초 구간을 자동 선택해 최대 6개를 순차 분석합니다. 겹치는 구간을 줄이고 여러 시간대의 장면을 선택합니다.
6. 각 구간의 강점·연습할 행동·근거 시각·불확실성·다음 행동을 즉시 저장합니다. 대시보드·영상·리포트에서 확인합니다.

원본 전체는 서버에 전송하지 않습니다. 정지 화면만 사용자 동의 후 서버를 통해 OpenAI에 전송합니다. 원본은 등록한 기기·브라우저·사이트 주소의 IndexedDB에 보관됩니다. 다른 기기와 자동 동기화되지 않습니다.

## 분석 범위와 한계

- 전체 **시간대의 표본 탐색**이며 모든 프레임을 연속 추적하는 방식이 아닙니다. 짧은 플레이, 가려진 번호, 작은 선수, 흐린 촬영에서는 중요한 장면을 놓칠 수 있습니다. 미발견은 영상에 선수가 없다는 뜻이 아닙니다.
- 모델이 확인한 번호와 행동도 코치 확인 전 AI 초안입니다. 실제 유소년 경기의 식별 정확도나 코칭 타당성을 검증한 제품은 아닙니다.
- AI 관찰을 종합 능력치·전국 순위·정신건강·성격·잠재력으로 환산하지 않습니다. 스파이더맵은 사람이 직접 근거와 함께 입력한 1~5단계 관찰 평가만 반영합니다. 미관찰 항목은 null입니다.
- 분석은 브라우저에서 진행합니다. 화면을 열어 두어야 하며 화면을 닫거나 기기가 절전되면 중단될 수 있습니다. 배치마다 탐색 상태, 구간마다 결과를 저장하며 다음 실행 때 저장한 지점부터 이어갑니다. 독립된 서버 백그라운드 작업이 아닙니다.
- 예시 리포트는 실제 기록과 분리됩니다. 일반 훈련 계획은 사람이 기록한 관찰 평가에 따른 규칙 기반 제안이며 AI의 임의 점수로 만들어지지 않습니다.

## 실행과 검증

Node.js 22 이상. 외부 npm 의존성은 없습니다.

```sh
cd /workspace/Soccer
npm run check
npm test
npm run export
npm start
```

기본 포트는 3000, 변경은 PORT, 개발 중 재시작은 `npm run dev`입니다. GET /api/workspace는 개발용 단일 워크스페이스이며 `.data/workspace.json`에 저장합니다. `NEXT_XI_DATA_DIR`로 위치를 변경할 수 있습니다. 공개 다중 사용자 API가 아니며 로그인·회원별 권한·보호자 동의 검증은 연결되지 않았습니다. Git worktree는 필요하지 않습니다.

브라우저 검증에는 Python Playwright, `/usr/bin/chromium`, FFmpeg가 필요합니다.

```sh
python3 tests/browser.py
python3 tests/original-browser.py
python3 tests/auto-analysis-browser.py
```

실제 H.264 파일을 생성해 디코딩·JPEG 추출·자동 구간 선택·전송·진행 저장·분석 결과 저장·재개·삭제·모바일 화면을 검증합니다. **AI 응답은 모의 처리합니다.** 실제 선수의 등번호 식별 성능·AI 답변 품질·API 과금 상태를 검증했다는 의미는 아닙니다.

## AI 서버와 배포

같은 출처의 `/api/analysis`에 요청합니다. `mode:'discover'`는 표본에서 남색 11번을 찾고, mode를 생략한 요청은 12초 이하 구간을 분석합니다. 서버 키와 12자 이상 이용 코드, 동일 출처 검사, 요청당 3 MB·이미지 250 KB·응답 시간 제한을 적용합니다. 이미지·키·이용 코드는 결과 기록에 저장하지 않습니다.

| 서버 환경변수 | 내용 |
| --- | --- |
| SOCCER_AI_API_KEY | 서버에서만 사용하는 OpenAI API 키 |
| SOCCER_ANALYSIS_ACCESS_CODE | 12자 이상의 비공개 분석 이용 코드 |
| SOCCER_AI_MODEL | 선택 사항, 기본 gpt-4.1-mini |

서버에 기존 OPENAI_API_KEY가 있으면 대체할 수 있습니다. 키를 HTML·GitHub 파일·대화창에 넣지 않습니다. 이용 코드는 비공개 파일럿용 장치이며 회원별 로그인·과금 한도 시스템을 대신하지 않습니다. API 이용료는 ChatGPT 구독과 별도입니다.

사용자는 기존 Netlify 프로젝트 courageous-entremet-c8f097을 GitHub의 `next-xi-download-20261016` 브랜치에 연결했고 `/api/analysis`의 ready 응답을 확인했습니다. 이 개발 환경에는 소유자의 Netlify 비밀값이나 API 키가 없습니다. ready는 필수 서버 설정의 존재만 확인하며 키의 유효성과 실제 AI 분석 성공을 증명하지 않습니다.

`netlify.toml`은 `npm run export`, publish `.artifacts/site`, functions `netlify/functions`, Node 22로 설정합니다. 연결한 브랜치에 푸시하면 Netlify의 자동 배포가 시작됩니다. 실제 배포 완료 여부는 Netlify에서 별도로 확인합니다. 정적 ZIP을 Drop에 올리는 방법은 서버 함수를 빌드하지 않습니다. 자세한 절차는 [배포 안내](docs/analysis-deployment.md)에 있습니다.

## 저장과 배포 파일

- 원본 최대 2 GiB. 기기의 실제 저장 한도와 재생 가능한 코덱에 따라 제한됩니다. 저장 실패와 목록 저장 실패를 구분하며 Blob을 되돌립니다.
- 브라우저 저장소가 삭제되면 원본이 사라질 수 있습니다. 같은 이름·크기의 원본 재연결, 원본 내보내기와 기록 JSON 내보내기를 제공합니다. JSON에 원본 바이트는 포함되지 않습니다.
- 삭제 시 영상의 관찰·AI 결과·자동 분석 진행 기록과 해당 기기의 Blob을 제거합니다.
- `npm run export`: 브라우저 저장소를 사용하는 단일 HTML과 `.artifacts/site` 생성.
- `python3 scripts/package-release.py`: 정적 ZIP 2종과 서버 포함 소스 ZIP, SHA256 목록 생성. 개인 데이터·환경 비밀값·Git 메타데이터를 포함하지 않습니다.

## 구성

- public/auto-analysis.js: 전체 시간대 표본 계획과 자동 구간 선택
- public/analysis-client.js: 실제 원본 디코딩, 프레임 준비, 자동 탐색·분석·재개
- lib/analysis.js: 인증·검증 및 실제 OpenAI 요청
- netlify/functions/analysis.mjs: Netlify 서버 함수
- public/domain.js: 하위 호환 데이터 검증·보관
- public/app.js, public/styles.css: 모바일 화면과 사용 흐름
- server.js: 개발용 HTTP 서버와 JSON 저장 API
- tests/: 단위·HTTP·실제 브라우저 검증
