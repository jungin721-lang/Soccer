# NEXT XI · v2.4

유소년 선수의 **원본 경기 영상 → 근거가 있는 피드백 → 날짜별 훈련·생활·식사 계획**을 연결하는 모바일 웹앱입니다. 현재 시작 화면은 `public/growth-app.js`이며, 이전 기기 저장형 v1과 서버·데이터 구조가 다릅니다.

새 `/video-clips.html`에서 원본을 약 1분씩 나눈 **연속 동영상**으로 준비할 수 있습니다. 스마트폰에서 한 조각씩 만들고 저장하며, 구간 경계 5초 겹침·30초 모드·원본 시각 정보·취소와 재시도를 제공합니다. 로그인·API 결제·원본 전송 없이 기기에서 처리하며 선수 탐색이나 AI 분석을 실행하지 않습니다. 실제 브라우저별 지원과 한계, 검증 명령은 [영상 나누기 안내](docs/video-clips.md)를 참고하세요. 기존 정지화면 준비 도구도 유지합니다.

**v2.4는 Cloudflare Workers AI 무료 분석 경로를 구현했습니다.** 매 요청 전 무료 계정 상태를 검사하고, 유료 가능성이 있거나 확인할 수 없으면 추론을 차단합니다. 기존 OpenAI 키로 전환하지 않습니다. 현재 개발 환경에는 Cloudflare 계정 연결 정보가 없어 실제 공급자 호출·경기 식별 정확도는 검증하지 못했습니다. [스마트폰 운영자 연결 안내](/public/free-analysis-setup.html)와 [공식 출처·설정 문서](docs/free-cloudflare-analysis.md)를 제공합니다.

`/feedback.html`에서는 채팅에서 검토한 피드백 JSON 또는 비공개 링크를 열고 근거 시각·관찰과 해석·구체적인 훈련을 확인합니다. 저장을 선택하면 이 기기의 IndexedDB에만 보관합니다. 개인 피드백은 공개 소스에 포함하지 않습니다. 이전 로컬 모델 조사 기록은 [별도 문서](docs/free-analysis.md)에 남깁니다.

**실제 운영 확인:** 2026-10-16 15:34:20 한국 시간에 [공개 사이트](https://courageous-entremet-c8f097.netlify.app)의 게시·소스 일치와 실제 Netlify 계정·Blobs 원본 저장·비공개 Range 재생·로그아웃 후 서버 처리·재로그인을 확인했습니다. 당시 확인한 배포 커밋은 `b236a6c`입니다. 실제 OpenAI 호출은 **`analysis_quota_exceeded`**를 반환했습니다. 키 누락이나 인증 401로 진단하지 않으며, 실제 선수 분석 결과는 아직 생성하지 못했습니다. 새 v2.1의 이전 기록 가져오기·한도 대기/복구는 아래 소스 기능이며 추가 검증 결과는 [검증 기록](docs/validation-2026-10-16.md)에 별도로 남깁니다.

## 대용량 원본 대신 채팅용 작은 자료 만들기

`/chat-pack.html`은 로그인·API 키 없이 동작하는 별도 준비 화면입니다. 원본 파일을 서버에 올리지 않고 스마트폰 브라우저에서 여러 시점의 정지 화면과 시각 정보를 추출해 작은 JPEG·ZIP으로 만듭니다. 파일을 채팅에 첨부하는 동작은 사용자가 직접 선택하며, 채팅 결과를 앱의 검증된 AI 결과로 자동 저장하지 않습니다.

원본은 변경하지 않습니다. 서버 원본 업로드의 2 GiB 제한과 별개로 이 준비 기능은 최대 8 GiB의 파일 정보를 허용하지만, 실제 처리 가능 여부는 기기 메모리·영상 코덱·탐색 지원에 따릅니다. 생성 중 화면을 유지해야 하며, 브라우저 종료 뒤 서버에서 이어가는 작업이 아닙니다. 결과는 최대 6개 시간 구간의 정지 화면 표본이며 선수 자동 식별·모든 플레이 분석을 수행했다고 표시하지 않습니다. 작은 등번호·표본 사이 행동은 판단할 수 없을 수 있습니다.

추가 검증 명령: `npm run test:chat-pack`. [자료 준비 안내](docs/chat-pack.md)에 범위와 사용 흐름을 정리했습니다. 실제 기기·코덱·8 GiB 원본 전체를 검증한 것은 아닙니다.

## 사용하는 흐름

1. 성인 보호자가 이메일·비밀번호로 계정을 만들고 선수 정보를 설정합니다. 보호자 여부는 자기 확인이며 본인·법정대리인 인증은 구현하지 않았습니다.
2. 스마트폰 사진첩이나 파일 앱에서 원본을 선택합니다. 영상마다 유니폼 색상·등번호·경기 날짜·촬영 조건을 지정합니다. 남색 11번에 고정되지 않습니다.
3. 업로드·분석 동의 후 원본을 계정 전용 서버 저장소로 보냅니다. 진행률을 표시하고, 끊기면 같은 기기·브라우저에서 같은 파일을 다시 선택해 받은 지점부터 이어 올립니다.
4. 업로드 완료 후 서버가 자동 분석을 시작합니다. 이용자가 API 키나 분석 이용 코드를 입력하지 않습니다. **업로드 중에는 화면을 유지해야 하지만, 서버 분석은 브라우저를 닫아도 계속됩니다.**
5. 경기 카드에서 상태·근거 시각·강점·연습 과제·식별 한계를 확인합니다. 실천 계획에서 4주 달력, 15분 연습, 생활 루틴과 7일 식사 예시를 확인하고 실천·컨디션을 기록합니다.

같은 배포 주소에서 같은 계정으로 로그인하면 PC와 스마트폰이 서버 기록을 공유합니다. 계정마다 자신의 원본과 기록에만 접근하며, 코치 초대·스카우터 공개 검색·제3자 공유 권한은 없습니다.

## 실제 분석 범위

- 서버 FFmpeg가 원본 전체 시간대에서 **1초 간격과 마지막 시점**의 표본을 추출합니다. 지정 색상·등번호가 확인된 모든 표본 주변을 최대 3초 구간으로 연결하고, 겹치는 범위를 병합·분할합니다. 첫 6개만 선택하던 제한은 무료 경로에서 제거했습니다. 구간별 최대 4개의 실제 시각이 기록된 JPEG로 정성 관찰을 요청합니다.
- 시간대별 표본 탐색입니다. 연속 선수·공 추적이나 모든 플레이의 전수 분석이 아니며, 짧은 플레이·작거나 가려진 번호를 놓칠 수 있습니다. 미발견은 선수 부재의 증명이 아닙니다.
- 원본은 앱 서버에 저장하고, 필요한 JPEG 이미지만 동의 후 Cloudflare API로 보냅니다. 영상 속 다른 사람도 이미지에 포함될 수 있습니다. AI는 동영상 전체 프레임을 직접 읽는 방식이 아닙니다.
- 분석 결과와 모든 비공개 근거 MP4가 저장되고 다시 읽혀 확인된 경우 큰 서버 원본을 자동 삭제합니다. 실패·한도 대기·취소·선수 미확인 시에는 보관합니다. 근거 생성·삭제 중 끊기면 저장된 지점부터 재개합니다. 휴대폰 사진첩 원본은 변경하지 않습니다.
- 결과는 근거 시각이 있는 **정성적 AI 초안**입니다. AI가 능력치·전국 순위·미래 가능성·성격·건강 진단을 생성하지 않습니다. 스파이더맵은 사람의 근거 평가만 사용하며, 기록이 없으면 관찰 부족으로 남습니다.
- 이전 경기 숫자 비교에는 동일 대상·유사한 경기 맥락, 경기별·항목별 최소 3개의 사람 평가가 필요합니다. 현재 화면은 AI 정성 관찰을 보여주며, 전문 코치 평가 입력 도구는 별도 확장 범위입니다.
- 원본 재생은 브라우저 코덱 지원에 따릅니다. MOV·HEVC를 모든 기기에서 재생하도록 변환하는 기능은 없습니다. 서버 프레임 추출과 브라우저 재생 가능 여부도 별개입니다.

## 로컬 실행

Node.js **24 이상**과 잠금파일 기준 설치가 필요합니다. `ffmpeg-static` 설치에는 검증을 유지한 바이너리 다운로드가 포함됩니다. 로컬 FFmpeg 경로는 `SOCCER_FFMPEG_PATH`로 지정할 수 있습니다.

```sh
cd /workspace/Soccer
npm ci
npm run check
npm test
npm start
```

기본 주소는 `http://localhost:3000`입니다. `PORT`로 포트, `NEXT_XI_DATA_DIR`로 데이터 폴더를 변경합니다. 개발 재시작은 `npm run dev`입니다. 기존 체크아웃을 사용하며 별도 Git worktree가 필요하지 않습니다.

로컬은 `.data/growth.sqlite`에 계정별 메타데이터와 원본 바이너리를 저장합니다. 원본은 최대 **2 GiB**, 업로드 조각은 **2 MiB**입니다. Netlify 배포에서는 Netlify Blobs를 사용합니다.

무료 계정 연결 없이도 계정·업로드·재생·실천 계획을 사용할 수 있습니다. 분석 결과를 꾸며내지 않습니다. 운영자는 서버의 `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`에 무료 계정과 Workers AI Read·Billing Read 권한을 연결합니다. 모델은 `@cf/mistralai/mistral-small-3.1-24b-instruct`로 고정합니다. 일반 사용자는 개발용 키·분석 이용 코드를 입력하지 않습니다. 과거 OpenAI 동의 작업을 새 공급자에게 자동 전송하지 않으며 새 동의가 필요합니다.

## 배포와 작업 지속

기존 Netlify 프로젝트를 Git 저장소의 `next-xi-download-20261016` 브랜치에 연결해 **소스 전체를 빌드**합니다. `netlify.toml`에 Node 24, `npm run export`, `.artifacts/site`, `netlify/functions`가 지정되어 있습니다. 정적 ZIP을 Drop에 올리는 것만으로는 v2 계정·저장·분석 서버가 생기지 않습니다. [배포 안내](docs/analysis-deployment.md)에 상세 구성을 정리했습니다.

백그라운드 작업은 8분 예산 안에서 체크포인트를 저장하고 다음 실행으로 이어갑니다. Netlify의 15분 백그라운드 실행 한도를 전제로 한 구조이며, `growth-recovery`가 10분마다 중단·대기 작업을 재전달합니다. 예약 복구는 20초 실행 예산, 호출당 최대 8초 대기, 저장된 검색 위치와 실행 잠금으로 다음 실행에 이어갑니다. 실제 Netlify에서 6초 합성 원본을 서버가 읽고 길이를 확인해 탐색 요청까지 진행했습니다. 긴 영상의 연속 실행·전체 복구·모든 기기 호환까지 검증한 것은 아닙니다. 로컬 서버는 시작 시와 1분마다 복구를 확인합니다.

v2.1의 `GET /api/v2/status`는 `configured`와 `liveVerified`를 구분합니다. `configured:true`는 서버 키 형식·설정 상태이며 `liveVerified:true`는 실제 공급자 응답 성공 후에만 표시합니다. 이것도 선수 식별 정확도나 경기 분석 전체 성공을 뜻하지 않습니다. 할당량 오류 상태는 `reason:provider_quota`, `available:false`, `configured:true`, `liveVerified:false`로 제공합니다.

## API 한도에 따른 대기·자동 재개

Cloudflare Workers Free의 무료 할당량은 **10,000 Neurons/일**이며 매일 00:00 UTC, 한국 시간 오전 9시에 갱신됩니다. 실제 무료 할당량 오류 `3036`을 받으면 `blocked`로 저장하고 원본·완료 결과를 유지합니다. 갱신 시각 이후 서버가 단일 확인 권한을 획득해 실제 요청을 확인합니다. 시간이 지났다는 이유만으로 정상화하지 않으며 스케줄러 주기에 따라 재개가 늦어질 수 있습니다.

원본 삭제는 저장 공간을 비우며 사용한 AI·Netlify 실행·전송 사용량을 되돌리지 않습니다. 무료 AI 경로가 Netlify의 저장·호스팅·전송 비용까지 보장하지는 않습니다. 앱의 계정 연결 점검은 사람이 없는 합성 JPEG만 전송하며, 서비스 전체 하루 5회·1분 간격으로 제한합니다. 실제 응답 검증과 실제 경기 선수 식별 정확도는 별개입니다.

## 훈련·생활·식사 생성

- 한국 날짜 기준 28일 계획입니다. 식별된 선수의 보통/높은 확신 개선 관찰이나 사람의 개선 기록을 규칙 기반으로 연결합니다. 근거가 없으면 일반 기초 연습이라고 표시합니다.
- 개인 연습은 준비 3분·본운동 9분·정리 3분, 총 15분입니다. 4주 동안 양을 늘리지 않고 동작의 질과 선택을 발전시킵니다. 팀·경기 날 추가 개인 훈련을 넣지 않고, 주 최대 3회와 휴식일을 우선합니다. 기존 일정 자체가 과밀하면 경고합니다.
- 일정 이동·실천·수면·피로·기분·통증을 날짜별로 저장합니다. 통증·높은 피로는 휴식으로 바꾸며 밀린 양을 몰아서 시키지 않습니다. 컨디션과 식품 제한은 별도의 선택 동의가 있어야 저장합니다.
- 7일 식사에는 준비법·대안·장보기·급식 보완 안내가 있습니다. 인식한 알레르기 재료를 제외하지만 제품 성분·교차 접촉 안전을 보장하지 않습니다. 모르는 알레르기·중증·치료식은 자동 메뉴 생성을 보류합니다.
- 공식 본문 **6개(CDC·AAP·FDA)를 직접 확인**했고, USDA·NIH 2개 참고 후보는 미확인으로 유지합니다. 문서 표시일·인용·해시·콘텐츠 버전을 기록했으며, 전문가의 개별 검토를 받았다는 뜻은 아닙니다. [출처 기록](docs/health-sources.md)과 화면에 해당 상태를 표시합니다.

브라우저 검증에는 Python Playwright·Chromium·FFmpeg가 필요합니다. 실제 MP4, 로컬 계정·원본 저장, 업로드 재시도·화면과 서버 처리 경로를 검증하며 AI 응답은 테스트에서 모의 처리합니다. 테스트 통과는 선수 식별 정확도·코칭 효과·유료 API 성공을 의미하지 않습니다. 개발 환경에 실서비스 비밀 키를 복사하지 않고 배포된 서버의 기존 바인딩으로 실제 클라우드를 확인했습니다. 계정·Blobs·원본 서버 처리는 확인했지만 **실제 AI 결과 생성은 공급자 할당량 오류로 중단**됐습니다. 구 v1 브라우저 스크립트는 현재 시작 화면의 검증 명령이 아닙니다.

현재 없는 기능: 이메일 인증·비밀번호 재설정, 법정대리인 본인 확인, 코치별 ACL, 웹 푸시, 운영자 화면, 보관기한 자동 정리·중단 업로드 자동 정리·독립 백업 운영. 영상·계정 삭제와 JSON 내보내기는 제공하지만 대규모 공개 서비스가 완성됐다는 뜻은 아닙니다. AI 학습용 동의는 기본 false이며 학습용 제공을 수집하지 않습니다.

## v1 기록을 명시적으로 가져오기

v1 localStorage·IndexedDB는 읽기만 하며 **원본을 덮어쓰거나 삭제하지 않습니다.** 같은 주소·기기·브라우저에서 이전 자료를 찾으면 가져오기 안내를 제공합니다. 동의 후 과거 메타데이터를 먼저 서버 보관함에 저장하고, 남아 있는 IndexedDB 원본은 파일 선택창 없이 순차 전송합니다. 중간에 끊겨도 원본 연결 지도를 점진적으로 저장하고 같은 아카이브는 중복 생성하지 않습니다.

원본이 없거나 다른 기기·주소인 경우에도 장면 설명·과거 해석·스냅샷을 보관하며 연결할 수 없는 원본을 명확히 알립니다. 보관 출처는 `legacy_browser_unverified`입니다. 과거 점수·AI 해석을 현재 능력치나 현재 AI 결과로 합치지 않고 현재 선수 설정도 자동 변경하지 않습니다. 유튜브 링크에서 영상을 다운로드하지 않습니다. 가져온 서버 영상 삭제 시 연결된 아카이브도 정리되지만 기기 원본은 남습니다. 아카이브만 삭제하면 서버 영상은 별도로 유지합니다.

구조·화면·권고 규칙은 [제품 설계](docs/product-design.md), 서버 설정·오류 진단은 [배포 안내](docs/analysis-deployment.md)에 정리했습니다. 저장·전송·추론 비용은 실제 사용량과 공급자 요금에 따라 달라지며, 비용 추정은 결제 사실이나 확정 가격이 아닙니다.
