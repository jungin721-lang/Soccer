무료 한도에서 멈추는 방식이에요

Cloudflare Workers AI 무료 할당량은 하루 10,000 Neurons입니다. 영상 길이와 응답량에 따라 처리량이 달라집니다. 다 쓰면 멈추고 한국 시간 다음 오전 9시 이후 다시 연결을 확인합니다.

앱은 매 분석 요청 전 계정 구독 목록을 확인합니다. 유료 구독이 있거나 무료 상태를 확인할 수 없으면 호출을 차단합니다. 기존 OpenAI 키로 전환하지 않습니다.

무제한 무료 서비스는 아닙니다. 원본 삭제는 저장 공간을 비우며, 사용한 AI 할당량이나 Netlify 저장·전송·실행 사용량을 되돌리지 않습니다.

2

계정 ID와 서버용 토큰 준비하기

어디서 찾나요?
  1. Cloudflare 대시보드에서 사용할 계정을 열고 Account ID를 복사합니다. 32자리 계정 ID입니다.
  2. API Tokens에서 Create Token → Create Custom Token을 선택합니다.
  3. Account 권한에 Workers AI · Read와 Billing · Read를 추가합니다. Account Resources는 해당 계정만 선택합니다.
  4. 생성한 전체 토큰을 다음 단계의 비밀 값 칸에 넣습니다. 이 토큰은 이 채팅이나 앱의 선수 화면에 붙여 넣지 않습니다.

Billing Read는 무료 상태 확인에 필요합니다. 권한이 없으면 추론 전에 차단합니다. 토큰이 공개됐다면 폐기하고 새로 발급합니다.

4

다시 배포하고 앱에서 연결 점검하기

  1. Netlify의 Deploys → Trigger deploy → Deploy site에서 새 배포를 실행합니다. 완료 표시가 Published가 될 때까지 기다립니다.
  2. 이 앱에 로그인하고 경기 영상 → 연결 상태 새로 확인을 누릅니다.
  3. 무료 분석 연결 점검을 누릅니다. 실제 경기 대신 사람이 없는 합성 이미지로 AI 응답을 확인합니다.
  4. 연결이 확인되면 원본을 선택하고 선수의 색상·등번호를 지정해 분석을 시작합니다.
앱으로 돌아가 연결 확인 →

연결 점검 통과는 실제 경기에서 11번을 정확히 찾는다는 보장이 아닙니다. 앱은 1초 간격 표본을 탐색하고 식별이 확인된 짧은 구간을 분석합니다. 흐리거나 가려진 번호, 표본 사이의 플레이를 놓칠 수 있으며 확인하지 못하면 평가를 보류합니다.

원본은 언제 삭제되나요?

분석이 완료되고 결과와 비공개 근거 클립이 안전하게 저장된 뒤 서버의 큰 원본을 삭제합니다. 스마트폰 사진첩의 원본은 삭제하지 않습니다. 실패·한도 대기·선수 확인 보류 상태에서는 재시도할 수 있도록 서버 원본도 남깁니다.

계정의 영상 삭제 버튼을 누르면 보관된 근거 클립과 해당 결과도 함께 삭제합니다.
